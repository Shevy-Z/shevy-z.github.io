答题统计 · 产品说明

1. 功能概述

答题统计用于从问卷、车型和问卷类型三个维度，监控答卷规模、作答效率与异常质量，帮助审核人员快速定位需复核样本。

本次更新

新增左侧「答题统计」菜单；人工审核的时长判定由正态假设调整为适配右偏数据的百分位规则。

核心操作

  1. 选择项目、周期和问卷状态后点击「查询」。
  2. 通过趋势与分布识别异常波动。
  3. 切换分析维度，在列表查看异常答卷并进入人工审核。

2. 人工审核 · 时长判断规则

实际答题时长通常呈右偏长尾，均值与标准差容易被极端值拉高。因此不再使用原正态分布 Z-score，改用分组百分位作为主判定。

建议规则异常 = t < P05 或 t > P95t = 有效作答时长；阈值按问卷版本 × 渠道分组计算

处理流程

1数据清洗排除预览、超时中断与无效记录
2分组计算对时长做 log1p 后计算 P05 / P95
3生成标记过短 / 正常 / 过长，写入判定版本
小样本保护

分组有效样本少于 200 时，回退到同问卷类型近 90 天基线；少于 50 时仅提示、不自动判异常。

落地改动

  • 离线任务：每日重算分组阈值，并保留规则版本与样本窗口。
  • 审核接口：返回 duration_status、threshold_low、threshold_high 与判定原因。
  • 页面列表：展示阈值、异常类型及规则状态，支持筛选并跳转人工审核。
  • 上线验收：历史 30 天回放，对比人工命中率、误报率和异常覆盖率。

3. 字段与指标口径

有效答题时长
提交时间减开始时间，扣除页面切后台超过 5 分钟的停留段。
异常率
时长异常答卷数 ÷ 有效答卷数。
P05 / P95
同分组有效时长在当前滚动窗口内的第 5 / 95 百分位值。
人工审核
异常样本进入待审核池，由审核员确认通过或驳回。

PRODUCT BRIEF · V1.6

答题统计 · 产品说明

1. 功能概述

答题统计用于从问卷、车型和问卷类型三个维度，监控答卷规模、作答效率与异常质量，帮助审核人员快速定位需要复核的样本。

页面定位

页面集中展示品牌级核心指标及三个业务维度的明细列表，并提供有效分位配置入口。

01总览指标查看答题量、答卷量、均值、标准差和有效时长。
02分位配置配置题目级上分位与答卷级下分位阈值。
03维度明细按问卷、车型、问卷类型定位异常数据。

2. 页面操作说明

查询与查看

  1. 选择调研项目、数据周期和问卷状态，点击「查询」刷新当前统计结果。
  2. 在关键指标区查看全品牌答题与答卷的数量、均值、标准差和有效时长。
  3. 通过答题与答卷有效分位配置调整时长判断阈值，再切换问卷、车型或问卷类型查看明细。
  4. 使用列表搜索、筛选和分页定位目标记录；需要留存时可导出当前报表。

分位配置

  • 点击「答题有效分位」设置题目级分位上限，默认 P ≤ 95.00%。
  • 点击「答卷有效分位」设置答卷级分位下限，默认 P ≥ 5.00%。
  • 确认后配置保存在当前浏览器，并同步更新按钮中的当前值。

3. 人工审核 · 时长判断方案

实际答题时长通常呈右偏长尾，均值与标准差容易受极端值影响。生产判定建议以同分组经验百分位为主，正态 Z-score 作为历史兼容与指标解释口径。

建议主规则异常 = t < P05 或 t > P95t 为有效作答时长；阈值按问卷版本 × 渠道等同质分组计算。

处理流程

1数据清洗排除预览、超时中断与无效记录
2分组计算计算经验 P05 / P95 阈值
3生成标记输出过短、正常、过长及原因
小样本保护

分组有效样本少于 200 时回退到同问卷类型近 90 天基线；少于 50 时仅提示，不自动判定异常。

落地改动

  • 离线任务：重算分组阈值，并保留规则版本与样本窗口。
  • 审核接口：返回状态、上下阈值、分位值和判定原因。
  • 页面列表：展示异常类型与规则状态，支持筛选并跳转人工审核。
  • 上线验收：回放历史数据，对比人工命中率、误报率和异常覆盖率。

4. 字段与指标口径

以下公式均在当前筛选条件和同一统计分组内计算。题目级以有效作答记录为样本，答卷级以完成问卷的推定时长为样本。

4.1 数量指标

答题总量n题 = ∑r∈R题 𝟙(r 为有效题目作答记录)R题为筛选范围内全部题目作答记录；𝟙(条件)成立取 1，否则取 0。
答卷总量n卷 = ∑q∈R卷 𝟙(q 已完成且有效)预览、未提交、缺少开始或提交时间、无效样本不计入。

4.2 平均时长

平均答题时长μ题 = (1 / n题) · ∑j=1n题 xjxⱼ 为第 j 条有效题目作答时长，单位为秒。
平均答卷时长μ卷 = (1 / n卷) · ∑k=1n卷 ykyₖ 为第 k 份完成答卷的推定时长，统一换算为秒或分钟。

4.3 标准差

答题标准差σ题 = √[(1 / n题) · ∑(xj − μ题)²]反映单题作答时长的离散程度。
答卷标准差σ卷 = √[(1 / n卷) · ∑(yk − μ卷)²]反映整份答卷推定时长的离散程度。
总体标准差口径

页面按当前分组的全量有效数据计算，因此分母使用 n。若抽样估计总体，应将分母改为 n − 1。

4.4 有效答题时长

生产规则优先采用适配右偏分布的经验百分位。默认上限为第 95 百分位，超过上限的超长单题按原业务方案使用 μ题 / 3 替代。

经验百分位上限T题,95 = Q0.95({x₁, x₂, …, xn题})Qₚ 表示样本排序后的第 p 分位数；配置值变化时将 0.95 替换为 p题。
正态兼容口径T题,p = μ题 + σ题 · Φ−1(p题)仅在沿用正态假设时使用；Φ⁻¹ 为标准正态分布的反函数。
单题有效时长xi* = { xi，P题,i < p题； μ题/3，P题,i ≥ p题 }P题,i = Φ[(xᵢ − μ题) / σ题]；默认 p题 = 95%。

4.5 有效答卷时长与审核判断

单份答卷推定时长yk = ∑i=1mₖ xk,i*mₖ 为第 k 份答卷包含的题目数；若页面以分钟展示，则再除以 60。
答卷经验分位下限T卷,05 = Q0.05({y₁, y₂, …, yn卷})默认取第 5 百分位；配置值变化时将 0.05 替换为 p卷。
答卷分位Z卷,k = (yk − μ卷) / σ卷；P卷,k = Φ(Z卷,k)正态兼容口径下，P卷表示该答卷在参考分布中的左侧累计分位。
异常判定异常k = 𝟙(P卷,k ≤ p卷)默认 p卷 = 5%；经验百分位方案等价写为 𝟙(yₖ ≤ T卷,05)。

4.6 异常率与人工审核

答卷时长异常率异常率 = (∑k=1n卷 异常k / n卷) × 100%分母仅包含满足当前筛选条件的有效完成答卷。
正常
P卷高于配置下限，保留正常状态。
异常
P卷不高于配置下限，标记为答题过快或疑似乱答，并进入人工审核。
待定
样本不足或 σ = 0，无法稳定计算分位时不自动判异常。
计算注意事项

所有时长必须先统一单位；同一指标应按车型、问卷版本等同质分组计算。实际数据明显右偏时使用经验 Qₚ，不应直接用 μ ± zσ 替代。

页面说明版本：V1.6 · 更新时间：2026-10-23

1. 功能概述

本模块用于解释答题统计页面中题目级、答卷级时长指标的来源，以及异常答卷进入人工审核的判断过程。统计分别以车型下的题目作答记录和车型下的完整问卷记录为口径。

01题目级推定识别超长单题，计算每份答卷的推定答题时长。
02答卷级审核识别过快或疑似乱答答卷，进入人工审核。
03增量补偿以旧统计量和新增样本滚动更新均值、标准差及分位。

页面入口

  • 「答题有效分位」配置题目级分位上限，默认 P ≤ 95.00%。
  • 「答卷有效分位」配置答卷级分位下限，默认 P ≥ 5.00%。
  • 问卷、车型、问卷类型三个列表展示 n、μ、σ 及有效时长结果。
口径关系说明

四张原图采用均值、标准差、Z 值和正态分布函数 Φ(z) 计算分位。实际答题时长若呈明显右偏长尾，生产判定应优先采用同分组的经验百分位；Z-score 方案作为指标推导和历史兼容口径保留，避免把“正态假设”误当成业务数据的必然分布。

2. 第一步：推定用户答题时长

统计口径为题目维度。针对某一车型下所有问卷，收集实际单题作答时长集合 {x₁, x₂, …, xₙ}，其中 n 为答题记录数。

1

准备样本剔除预览、未提交、无开始时间等无效记录；按车型及题目口径聚合。

2

计算题目均值得到该车型下所有相关题目的平均答题时长 μ题。

3

计算题目标准差得到 σ题，作为后续 Z 值与分位 P题的计算依据。

题目平均时长μ题 = 1/n题 · ∑ xjj = 1 … n题
题目标准差σ题 = √[1/n题 · ∑(xi − μ题)²]总体标准差口径

单题分位与替代

对某 VIN 的每次作答时长 xᵢ，计算 Z题及 P题。当 P题达到配置的上分位（默认 95%）时，图示原口径将该超长记录从有效统计中剔除，并以 1/3 μ题补偿替代。

标准化Z题 = (xi − μ题) / σ题
题目分位P题 = Φ(Z题)
若 P题 < P上限
保留 xᵢ＋若 P题 ≥ P上限
替换为 μ题 / 3＝汇总并换算分钟
推定时长 y
需要业务确认

“超长记录以 1/3 μ题替代”来自原图规则，会明显压低推定时长。正式上线前建议通过历史回放确认替代系数，或改为截尾值 P95 / 温莎化处理。

3. Φ(z) 与分位的含义

标准正态曲线下总面积为 1。Φ(z) 表示从负无穷到当前 z 值的左侧累计面积，也就是当前记录在参考分布中的累计分位。

标准正态累计分布函数Φ(z) = 1/2 [1 + erf(z / √2)] = ∫−∞z (1 / √2π) e−t²/2 dt
z = 0
位于均值，累计分位为 50%。
z = −1
低于均值一个标准差，左侧面积约为 15.87%。
z 越大
记录位于分布更靠右的位置，P 越接近 100%。

4. 第二步：标识答卷异常

统计口径切换为问卷维度。针对同一车型下所有已回答问卷，使用第一步得到的推定答题时长集合 {y₁, y₂, …, yₙ}，其中 n 为完成答卷数。

1

计算答卷均值 μ卷统计同车型已完成问卷的推定答题时长。

2

计算答卷标准差 σ卷描述完整答卷时长的离散程度。

3

计算 P卷并审核识别分布左尾的过快答卷或疑似乱答记录。

答卷平均时长μ卷 = 1/n卷 · ∑ yj
答卷标准差σ卷 = √[1/n卷 · ∑(yi − μ卷)²]
答卷 Z 值Z卷 = (yi − μ卷) / σ卷
答卷分位P卷 = Φ(Z卷)
默认审核规则P卷 ≤ 5.00% → 异常回答异常原因：答题过快或疑似乱回答；进入人工审核表单并高亮展示。

审核输出

结果条件页面处理
异常P卷 ≤ 配置下限高亮并进入人工审核
正常P卷 > 配置下限保留正常状态
待定样本不足或 σ = 0不自动判定，提示复核

5. 历史统计量的补偿计算

历史数据量较大时，无需每新增一条记录就全量重算。系统可使用旧样本量、旧均值、旧标准差和新增数据，精确滚动更新最新统计量；该计算是数学等价更新，并非近似。

旧统计量n旧、μ旧、σ旧＋新增记录x新→新统计量n新、μ新、σ新、Z新、P新
新的样本量n新 = n旧 + 1
新的均值μ新 = (n旧 μ旧 + x新) / n新
新的标准差σ新 = √{[n旧σ旧² + (n旧/n新)(x新−μ旧)²] / n新}
新的 Z 值Z新 = (x新 − μ新) / σ新
新的 P 值P新 = Φ(Z新)
实现要求

每次更新必须保存样本量、均值、标准差、规则版本和更新时间；按车型 × 问卷版本隔离统计状态。并发写入时使用原子更新或版本锁，防止样本量与均值错配。

6. 字段与配置口径

字段含义单位/默认值
xᵢ某 VIN 的单次题目实际作答时长秒
yᵢ完成异常替代后的单份问卷推定时长分钟
n题 / n卷答题记录数 / 完成答卷数条
μ题 / σ题题目级平均时长 / 标准差秒
μ卷 / σ卷答卷级平均时长 / 标准差分钟
P题上限题目超长记录的分位阈值95.00%
P卷下限过快答卷的审核阈值5.00%

边界与降级策略

  • σ = 0 时不可计算 Z 值，记录进入“待定”，不自动判断异常。
  • 有效样本少于 200 时回退至同问卷类型近 90 天基线；少于 50 时仅提示。
  • 缺失、负值、未完成和超时中断记录不进入统计样本。
  • 阈值修改后记录规则版本，历史结果不静默覆盖，支持重新回放。
